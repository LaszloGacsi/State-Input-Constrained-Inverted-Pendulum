# State-Input-Constrained-Inverted-Pendulum

Matlab codes for numerical simulation of the inverted pendulum using backup CBF with mixed state-input constraints. Please use the main.m file for running the simulation and generating the plots.

See details in our paper below. Please cite the paper if you use these codes for your research.

Enforcing Mixed State-Input Constraints with Multiple Backup Control Barrier Functions: A Projection-based Approach
Laszlo Gacsi, Adam K. Kiss, Ersin Das¸, and Tamas G. Molnar
